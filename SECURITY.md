# Reporting security issues

Do not include API keys, personal camera images, book projects or private configuration in public issues. If a key was exposed, revoke it with its provider.

Use the repository's private vulnerability reporting option if the maintainer has enabled it. If it is unavailable, open a minimal issue asking for a private contact method without disclosing exploit details or sensitive files. This document does not promise a response time or supported maintenance period.

Describe the affected version, operating system, reproduction steps and impact. Local configuration and provider credentials are user data and must not be included in release artifacts. Camera profiles contain declarative JSON rather than executable plug-ins. Cloud image transmission must remain explicit and visibly attributed to the selected provider.
