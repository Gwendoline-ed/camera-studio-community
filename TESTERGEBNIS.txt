Camera Studio Community 0.9.0 — verification, 2026-10-18
======================================================

Completed locally:
- 166 unit tests passed. Includes all six translation catalogs, literal call
  coverage, matching named placeholders/format specifications, locale fallback,
  isolated persistence, restart behavior and unchanged camera protocol values.
- GTK integration passed in en/de/da/es/pl/fr: five windows per language
  (main, AI, book, drawing, settings), synthetic video and a simulated Tiny 2.
  Selecting the translated upper-body button still sent the original correct
  tracking command. Saving the next language did not move the camera or stop video.
- Repeated all six language GUI runs on a separate Xvfb display. Initial native
  desktop runs passed; a later desktop screenshot timeout was isolated to the
  display session. Headless runs completed, including screenshots of 30 windows.
- Simulated Local/OpenAI/xAI/Gemini UI regression passed: isolated histories,
  explicit image dispatch, no requests on provider/settings changes, session-only
  key entry and automatic book AI remaining off by default.
- Six complete Markdown manuals and matching standalone HTML guides generated;
  guide resolution works for source and DEB layouts, without network access.
- Desktop launcher validated. Distribution source selection excludes Git data,
  caches, API keys, private configuration, local books and environment files.
- Release ZIP: all 114 manifest entries and archive CRC verified; six catalogs,
  six Markdown/HTML guides, license and GitHub workflow included. No Git metadata,
  credentials or personal configuration in either release artifact.
- Extracted DEB: French smoke test passed with 45 synthetic preview frames,
  32 controls and no camera access. All six installed offline guide paths resolved.
- Documentation links and workflow YAML validated locally. Local Git repository
  initialized on main, without remote publication.
- Original Tiny 2 Studio: all 102 baseline file hashes unchanged.

The GitHub workflow is prepared for Ubuntu 24.04. It has not been executed on
GitHub because no repository has been published during this task. Local tests
ran on the available Ubuntu host using Python 3.14 and distro GTK/GStreamer.
No live cloud requests or new physical-camera precision tests were performed.
Translations were written and reviewed during development, not certified by
professional native-language reviewers. External cover tools and system dialogs
retain their own language settings. OCR data remain German and English.
