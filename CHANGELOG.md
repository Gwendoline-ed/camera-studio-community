# Changelog

## 0.9.0 — 2026-10-18

- Add persistent language selection: English, German, Danish, Spanish, Polish and French. Apply on restart without interrupting live camera operation.
- Translate controls, dialogs, status/error messages, AI destination notices and local export labels. Preserve camera protocol IDs and user-authored text.
- Add six complete user guides in Markdown and offline HTML, accessible from the application.
- Request AI answers in the selected interface language. OCR remains German/English.
- Prepare the independent project for GitHub with MIT licensing, third-party attribution, contribution instructions, issue templates, automated tests and build artifacts.
- Keep the original Tiny 2 Studio application and all of its settings unchanged.

## 0.8.0 — 2026-10-18

- Rename the Community chat interface to AI and add Local, ChatGPT, Grok and Gemini selection.
- Separate provider histories, explicit image sending and session-only keys by default.
- Add provider selection to book-page correction; retain local OCR and manual correction.
- Clarify that comic issue OCR uses a separate local cover tool.

## 0.7.0 — 2026-10-18

- Create a separate Community edition from Tiny 2 Studio 0.6.4.
- Keep Tiny 2 built in; add optional camera profiles and independent camera windows.
- Add V4L2 capture mode selection, custom device-declared size ranges and generic USB support.
